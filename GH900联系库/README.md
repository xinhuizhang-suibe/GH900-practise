# GH-900 GitHub Foundations Study Repository / 学习库

> **Goal:** Prepare for the English-language exam in 14 days. Study for at least two hours each day, understand the concepts, and complete basic tasks on GitHub and with the Git CLI.  
> **目标：** 用 14 天准备全英文考试，每天至少学习 2 小时，理解核心概念，并能在 GitHub 网页和 Git CLI 中完成基础操作。

## How to Study / 使用方法

1. Open [01-十四天学习计划.md](01-十四天学习计划.md) each day, finish the tasks, and check the boxes.  
	 每天打开学习计划，完成当天任务并勾选清单。
2. Use [02-GH900知识手册.md](02-GH900知识手册.md) to understand concepts instead of memorizing answers only.  
	 学习时查阅知识手册，不要只背答案。
3. After each domain, answer the matching questions in [03-练习题.md](03-练习题.md) in English first.  
	 每学完一个领域，先用英文完成练习题中的对应题目。
4. Record every mistake in [04-错题本.md](04-错题本.md), including why the answer was wrong.  
	 把所有错题记入错题本，并写清错误原因。
5. Review on Days 7 and 14. Target at least 75% and 85% accuracy respectively.  
	 第 7 天和第 14 天进行复盘，目标正确率分别不低于 75% 和 85%。

## Use This Repository on GitHub / 在 GitHub 上打开使用

### Read Online / 在线阅读

1. Sign in to [GitHub](https://github.com/) and create a new repository.
2. Upload these six `.md` files to the repository and commit the changes.
3. Open the repository. GitHub displays `README.md` automatically on the home page.
4. Click any file link in the table above to read it. Markdown headings, tables, links, and checkboxes render directly in the browser.

中文步骤：登录 GitHub，新建仓库，上传这六个 `.md` 文件并提交。进入仓库后，GitHub 会自动显示 README；点击上表中的文件名即可在线阅读。

### Track Progress / 记录进度

- To check a task, open the file, select the pencil icon (**Edit this file**), change `- [ ]` to `- [x]`, and select **Commit changes**.  
	勾选任务时，打开文件并点击铅笔图标，把 `- [ ]` 改成 `- [x]`，然后点击 **Commit changes**。
- To use a VS Code-like editor in the browser, press the `.` key on the repository page or replace `github.com` with `github.dev` in the URL.  
	如需浏览器版 VS Code，在仓库页面按 `.` 键，或把网址中的 `github.com` 改为 `github.dev`。
- Changes made on GitHub are saved only after you create a commit.  
	GitHub 上的修改只有在提交 commit 后才会保存到仓库。

> [!NOTE]
> If the repository is public, anyone can read it. Choose a private repository if you do not want your study notes to be public.  
> Public 仓库所有人都能查看；如果不希望公开学习记录，请创建 Private 仓库。
