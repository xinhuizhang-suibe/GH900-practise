# GH-900 14-Day Study Plan / 十四天学习计划

Recommended daily schedule: 2 hours (45 minutes for concepts, 60 minutes for hands-on practice, and 15 minutes for review).  
每日建议学习 2 小时：概念 45 分钟、动手操作 60 分钟、复盘 15 分钟。

## Day 1: Git and GitHub Basics / 第 1 天：Git 与 GitHub 基础

- [ ] Understand Git, GitHub, repositories, local repositories, and remote repositories.<br>理解 Git、GitHub、仓库、本地仓库和远程仓库。
- [ ] Distinguish Git from GitHub.<br>区分 Git 与 GitHub。
- [ ] Learn commit, branch, merge, clone, push, pull, and fetch.<br>掌握 commit、branch、merge、clone、push、pull 和 fetch。
- [ ] Hands-on: Create a repository, add a README, and make a commit.<br>实操：创建仓库，添加 README，完成一次提交。
- [ ] Explain the working directory, staging area, and repository in your own words.<br>用自己的话解释工作区、暂存区和仓库。

## Day 2: Repositories and Files / 第 2 天：仓库与文件操作

- [ ] Learn the differences among public, private, and internal repositories.<br>学习 public、private、internal 仓库的区别。
- [ ] Learn the purposes of README, LICENSE, `.gitignore`, and CODEOWNERS.<br>学习 README、LICENSE、`.gitignore` 和 CODEOWNERS 的用途。
- [ ] Understand forks, clones, and template repositories.<br>理解 fork、clone 和 template repository。
- [ ] Hands-on: Create a branch and edit a Markdown file.<br>实操：新建分支并编辑 Markdown 文件。
- [ ] Practice Markdown headings, lists, links, code blocks, and task lists.<br>练习 Markdown 标题、列表、链接、代码块和任务列表。

## Day 3: Branches and Commits / 第 3 天：分支与提交

- [ ] Understand default branches, feature branches, and branch protection.<br>理解默认分支、功能分支和分支保护。
- [ ] Understand commit SHAs, commit history, and change comparisons.<br>理解 commit SHA、提交历史和变更比较。
- [ ] Compare the results of merge commit, squash merge, and rebase merge.<br>掌握 merge commit、squash merge 和 rebase merge 的结果差异。
- [ ] Hands-on: Make two commits on a feature branch and view the diff.<br>实操：在功能分支完成两个提交并查看 diff。
- [ ] Review common Git commands.<br>复习常用 Git 命令。

## Day 4: Issues and Discussions / 第 4 天：Issue 与讨论

- [ ] Compare the purposes of Issues, Discussions, and Pull Requests.<br>学习 Issue、Discussion 和 Pull Request 的用途差异。
- [ ] Learn assignees, labels, milestones, mentions, and linked issues.<br>掌握 assignee、label、milestone、mention 和链接 Issue。
- [ ] Understand issue templates and issue forms.<br>理解 Issue 模板和表单。
- [ ] Hands-on: Create an issue and add a label, an assignee, and a task list.<br>实操：创建 Issue，添加标签、负责人和任务列表。
- [ ] Practice linking issues with `#number` and closing keywords.<br>练习使用 `#编号` 和关键词关联 Issue。

## Day 5: Pull Requests / 第 5 天：Pull Request

- [ ] Learn the PR creation, draft, review, suggested change, and merge workflow.<br>掌握 PR 创建、草稿、审查、建议修改和合并流程。
- [ ] Distinguish comment, approve, and request changes.<br>区分 comment、approve 和 request changes。
- [ ] Understand reviewers, required reviews, and merge conflicts.<br>理解 reviewer、required review 和 merge conflict。
- [ ] Hands-on: Create a PR, add a comment, and apply a suggested change.<br>实操：创建 PR、添加评论并应用 suggested change。
- [ ] Understand what `Closes #number` does.<br>掌握 `Closes #编号` 的作用。

## Day 6: Collaboration and Permissions / 第 6 天：协作与权限

- [ ] Learn the Read, Triage, Write, Maintain, and Admin roles.<br>掌握 Read、Triage、Write、Maintain 和 Admin 权限。
- [ ] Understand the principle of least privilege.<br>理解最小权限原则。
- [ ] Learn about organizations, teams, outside collaborators, and repository roles.<br>学习组织、团队、外部协作者和仓库角色。
- [ ] Hands-on: Review the collaboration settings visible under repository Settings.<br>实操：查看仓库 Settings 中可见的协作设置。
- [ ] Complete permission-based scenario questions.<br>完成权限场景题。

## Day 7: Week 1 Review / 第 7 天：第一周复盘

- [ ] Explain the key terms from Days 1–6 without notes.<br>闭卷解释前 6 天关键词。
- [ ] Complete the first round of practice questions.<br>完成练习题第一轮。
- [ ] Add every incorrect answer to the mistake log.<br>将错题写入错题本。
- [ ] Retry every incorrect question and reach at least 75% accuracy.<br>重做所有错误题，目标正确率不低于 75%。
- [ ] Complete introductory GitHub Skills exercises.<br>补做 GitHub Skills 基础练习。

## Day 8: Project Management / 第 8 天：项目管理

- [ ] Learn the table, board, and roadmap views in GitHub Projects.<br>学习 GitHub Projects 的 table、board 和 roadmap 视图。
- [ ] Understand fields, filters, iterations, automation, and insights.<br>理解字段、筛选、迭代、自动化和洞察。
- [ ] Distinguish Projects, Milestones, and Issues.<br>区分 Projects、Milestones 和 Issues。
- [ ] Hands-on: Create a project board, add three issues, and change their status.<br>实操：建立项目看板，添加三个 Issue 并改变状态。
- [ ] Practice project-management scenario questions.<br>练习项目管理场景题。

## Day 9: Modern Development and Automation / 第 9 天：现代开发与自动化

- [ ] Understand GitHub Actions, workflows, events, jobs, steps, runners, and actions.<br>理解 GitHub Actions、workflow、event、job、step、runner 和 action。
- [ ] Understand the relationship between Actions and Marketplace.<br>理解 Actions 与 Marketplace 的关系。
- [ ] Compare Codespaces, github.dev, and local VS Code.<br>认识 Codespaces、github.dev 和本地 VS Code 的差异。
- [ ] Hands-on: Review a workflow YAML file and an Actions run.<br>实操：查看一个 workflow YAML 和 Actions 运行记录。
- [ ] Understand how status checks protect branches.<br>理解状态检查如何保护分支。

## Day 10: Security Fundamentals / 第 10 天：安全基础

- [ ] Learn 2FA, passkeys, PATs, SSH keys, and least privilege.<br>学习 2FA、passkey、PAT、SSH key 和最小权限。
- [ ] Understand Dependabot, the dependency graph, secret scanning, and code scanning.<br>理解 Dependabot、dependency graph、secret scanning 和 code scanning。
- [ ] Distinguish security advisories, private vulnerability reporting, and regular issues.<br>区分安全公告、私密漏洞报告和普通 Issue。
- [ ] Hands-on: Review a repository's Security page and Dependabot settings.<br>实操：查看仓库 Security 页面和 Dependabot 设置。
- [ ] Complete security scenario questions.<br>完成安全场景题。

## Day 11: Community and Open Source / 第 11 天：社区与开源

- [ ] Learn LICENSE, CONTRIBUTING, CODE_OF_CONDUCT, SUPPORT, and SECURITY files.<br>学习 LICENSE、CONTRIBUTING、CODE_OF_CONDUCT、SUPPORT 和 SECURITY 文件。
- [ ] Understand open source, InnerSource, and the forking workflow.<br>理解开源、InnerSource 和 forking workflow。
- [ ] Understand sponsor, star, watch, and follow.<br>理解 sponsor、star、watch 和 follow。
- [ ] Hands-on: Review the community health files in a public repository.<br>实操：检查一个公共仓库的社区健康文件。
- [ ] Practice license-selection and contribution-workflow questions.<br>练习选择许可证和贡献流程题。

## Day 12: Search, Notifications, and Ecosystem / 第 12 天：搜索、通知与生态

- [ ] Learn GitHub search qualifiers such as `repo:`, `is:`, `author:`, and `label:`.<br>学习 GitHub 搜索限定符，如 `repo:`、`is:`、`author:` 和 `label:`。
- [ ] Distinguish watch, subscribe, mention, and notification reasons.<br>区分 watch、subscribe、mention 和通知原因。
- [ ] Review Marketplace, GitHub Apps, and Actions.<br>复习 Marketplace、GitHub Apps 和 Actions。
- [ ] Hands-on: Search for open PRs, labeled issues, and commits by an author.<br>实操：搜索开放 PR、带标签 Issue 和某作者提交。
- [ ] Summarize commonly confused features in a comparison table.<br>汇总易混功能对照表。

## Day 13: Mock Exam and Targeted Review / 第 13 天：模拟与补弱

- [ ] Complete a timed mock exam.<br>限时完成一套模拟题。
- [ ] Mark uncertain questions without looking up answers during the exam.<br>标记不确定题，不边做边查。
- [ ] Calculate accuracy by domain.<br>统计各领域正确率。
- [ ] Focus on the two lowest-scoring domains.<br>集中复习最低分的两个领域。
- [ ] Retry incorrect questions and reach at least 85% accuracy.<br>重做错题，目标正确率不低于 85%。

## Day 14: Final Review / 第 14 天：考前总复习

- [ ] Quickly review the commonly confused concepts in the handbook.<br>快速复习知识手册中的易错对比。
- [ ] Explain a complete workflow aloud: Issue → branch → commit → PR → review → merge.<br>口述一个完整协作流程：Issue → branch → commit → PR → review → merge。
- [ ] Review permissions, security, Actions, and Projects.<br>复习权限、安全、Actions 和 Projects。
- [ ] Complete the final round of incorrect questions.<br>完成最后一轮错题。
- [ ] Review the pre-exam checklist and stop learning new material.<br>查看考前检查表，停止学习新内容。
