# GH-900 7-Day Intensive Study Plan / 七天高强度学习计划

Recommended daily schedule: 4 hours (90 minutes for concepts, 90 minutes for hands-on practice, 45 minutes for English questions, and 15 minutes for review).  
每日建议学习 4 小时：概念 90 分钟、动手操作 90 分钟、英文题 45 分钟、复盘 15 分钟。

> Answer questions in English first. Read the Chinese translation only when the English wording blocks your understanding.  
> 做题时先只看英文；只有英文表述影响理解时才查看中文翻译。

## Day 1: GitHub Foundations and Repositories / 第 1 天：GitHub 基础与仓库

- [x] Distinguish Git, GitHub, local repositories, remote repositories, and cloud-based services.<br>区分 Git、GitHub、本地仓库、远程仓库和云服务。
- [x] Learn commits, branches, repository visibility, and the default branch.<br>学习 commit、branch、仓库可见性和默认分支。
- [x] Learn README, LICENSE, `.gitignore`, CONTRIBUTING, SECURITY, and CODEOWNERS.<br>学习 README、LICENSE、`.gitignore`、CONTRIBUTING、SECURITY 和 CODEOWNERS。
- [ ] Compare clone, fork, and template repositories.<br>比较 clone、fork 和 _template repository_。
- [ ] Practice Markdown headings, links, tables, code blocks, and task lists.<br>练习 Markdown 标题、链接、表格、代码块和任务列表。
- [ ] Hands-on: Create a repository, add a README, edit a file, and make two commits.<br>实操：创建仓库、添加 README、编辑文件并完成两次提交。
- [ ] Complete the related questions in the handbook and explain every wrong option.<br>完成知识手册中的对应题目，并解释每个错误选项。

## Day 2: Git, Branches, and Merging / 第 2 天：Git、分支与合并

- [ ] Learn clone, add, commit, push, fetch, pull, branch, switch, merge, and diff.<br>学习 clone、add、commit、push、fetch、pull、branch、switch、merge 和 diff。
- [ ] Understand the working directory, staging area, local repository, and remote repository.<br>理解工作区、暂存区、本地仓库和远程仓库。
- [ ] Understand commit SHAs, history, comparisons, and merge conflicts.<br>理解 commit SHA、提交历史、变更比较和合并冲突。
- [ ] Compare merge commit, squash and merge, and rebase and merge.<br>比较 merge commit、squash and merge 和 rebase and merge。
- [ ] Learn protected branches, rulesets, required reviews, and required status checks.<br>学习受保护分支、规则集、必需审查和必需状态检查。
- [ ] Hands-on: Create a feature branch, make two commits, compare changes, and merge it.<br>实操：创建功能分支、完成两次提交、比较变更并合并。
- [ ] Complete branch and Git scenario questions in English.<br>完成英文分支与 Git 场景题。

## Day 3: Issues, Pull Requests, and Permissions / 第 3 天：Issue、PR 与权限

- [ ] Compare Issues, Discussions, Pull Requests, and draft pull requests.<br>比较 Issue、Discussion、Pull Request 和 draft pull request。
- [ ] Learn assignees, labels, milestones, mentions, linked issues, templates, and forms.<br>学习 assignee、label、milestone、mention、关联 Issue、模板和表单。
- [ ] Learn the PR workflow: create, review, comment, approve, request changes, and merge.<br>学习 PR 流程：创建、审查、评论、批准、请求更改和合并。
- [ ] Understand suggested changes, reviewers, closing keywords, and merge conflicts.<br>理解 suggested change、reviewer、关闭关键词和合并冲突。
- [ ] Compare Read, Triage, Write, Maintain, and Admin using least privilege.<br>按最小权限原则比较 Read、Triage、Write、Maintain 和 Admin。
- [ ] Hands-on: Create an Issue, link it to a branch and PR, request a review, and close it by merging.<br>实操：创建 Issue，关联分支与 PR，请求审查，并通过合并关闭 Issue。
- [ ] Complete collaboration and permission scenario questions in English.<br>完成英文协作与权限场景题。

## Day 4: Projects, Search, Notifications, and Ecosystem / 第 4 天：项目、搜索、通知与生态

- [ ] Learn GitHub Projects table, board, roadmap, fields, filters, iterations, automation, and insights.<br>学习 GitHub Projects 的 table、board、roadmap、字段、筛选、迭代、自动化和洞察。
- [ ] Distinguish Projects, Milestones, Issues, and draft issues.<br>区分 Projects、Milestones、Issues 和 draft issues。
- [ ] Learn search qualifiers such as `repo:`, `org:`, `is:`, `author:`, `label:`, and `language:`.<br>学习 `repo:`、`org:`、`is:`、`author:`、`label:` 和 `language:` 等搜索限定符。
- [ ] Distinguish watch, subscribe, mention, follow, star, and notification reasons.<br>区分 watch、subscribe、mention、follow、star 和通知原因。
- [ ] Understand GitHub Marketplace, GitHub Apps, GitHub Actions, github.dev, and Codespaces.<br>理解 GitHub Marketplace、GitHub Apps、GitHub Actions、github.dev 和 Codespaces。
- [ ] Hands-on: Build a project board and search for open labeled issues and pull requests.<br>实操：创建项目看板，并搜索开放的带标签 Issue 和 PR。
- [ ] Complete project, search, and ecosystem scenario questions in English.<br>完成英文项目、搜索和生态场景题。

## Day 5: Security, Administration, and Authentication / 第 5 天：安全、管理与身份验证

- [ ] Learn 2FA, passkeys, personal access tokens, SSH keys, scopes, expiration, and least privilege.<br>学习 2FA、passkey、PAT、SSH key、作用域、有效期和最小权限。
- [ ] Compare dependency graph, Dependabot alerts, and Dependabot security updates.<br>比较 dependency graph、Dependabot alerts 和 Dependabot security updates。
- [ ] Compare secret scanning, push protection, and code scanning.<br>比较 secret scanning、push protection 和 code scanning。
- [ ] Distinguish security advisories, private vulnerability reporting, and public issues.<br>区分 security advisory、private vulnerability reporting 和公开 Issue。
- [ ] Review organizations, teams, outside collaborators, repository roles, and visibility.<br>复习组织、团队、外部协作者、仓库角色和可见性。
- [ ] Hands-on: Review repository Security, access, branch rules, and Dependabot settings.<br>实操：查看仓库 Security、访问权限、分支规则和 Dependabot 设置。
- [ ] Complete security scenarios and explain the first risk-reduction action.<br>完成安全场景题，并解释首先应采取的降险操作。

## Day 6: Open Source, InnerSource, and Automation / 第 6 天：开源、InnerSource 与自动化

- [ ] Learn open source, InnerSource, forking workflows, licenses, and community health files.<br>学习 open source、InnerSource、forking workflow、许可证和社区健康文件。
- [ ] Understand sponsor, star, watch, follow, releases, tags, and wikis.<br>理解 sponsor、star、watch、follow、release、tag 和 Wiki。
- [ ] Learn GitHub Actions concepts: workflow, event, job, step, runner, action, and secret.<br>学习 GitHub Actions 概念：workflow、event、job、step、runner、action 和 secret。
- [ ] Understand how Actions, Marketplace, and required status checks work together.<br>理解 Actions、Marketplace 和 required status checks 如何配合。
- [ ] Hands-on: Inspect a workflow YAML file, an Actions run, and a public repository's community files.<br>实操：查看 workflow YAML、Actions 运行记录和公共仓库的社区文件。
- [ ] Complete the 20-question warm-up in `03-练习题.md` without notes and record mistakes.<br>闭卷完成 `03-练习题.md` 的 20 题热身练习并记录错题。
- [ ] Retry incorrect questions until accuracy reaches at least 85%.<br>重做错题，直到正确率不低于 85%。

## Day 7: Mock Exam and Final Review / 第 7 天：模拟考试与总复习

- [ ] Complete all 100 questions in `06-GH900百题题库.md` as a timed English mock exam without looking up answers.<br>把 `06-GH900百题题库.md` 的 100 题作为全英文限时模拟考试，过程中不查资料。
- [ ] Calculate accuracy by domain and review the two weakest domains.<br>统计各领域正确率，集中复习最低分的两个领域。
- [ ] Explain all commonly confused concepts without notes.<br>闭卷解释所有高频易混概念。
- [ ] Explain the complete workflow aloud: Issue → branch → commit → PR → review → merge.<br>口述完整协作流程：Issue → branch → commit → PR → review → merge。
- [ ] Review permissions, security, Actions, Projects, and repository files.<br>复习权限、安全、Actions、Projects 和仓库文件。
- [ ] Retry all mistakes and target at least 90% accuracy.<br>重做全部错题，目标正确率不低于 90%。
- [ ] Complete the pre-exam checklist and stop learning new material.<br>完成考前检查表，停止学习新内容。
